# Roadmap

This roadmap keeps the benchmark moving toward a credible public standard.

## Current

- Versioned foundation track.
- Versioned adversarial track.
- JSON report validation.
- Suite manifests.
- Baseline reports.
- Leaderboard snapshots.
- CI artifact validation.
- External JSON/JSONL prediction scoring.
- Machine-readable benchmark registry.
- Validated leaderboard submission metadata.
- Release manifest with SHA-256 artifact pinning.
- Diagnostic slice metrics by domain, difficulty, capability, and tag.
- Confidence calibration metrics from detector scores.
- Suite coverage profiles and quality gates.
- Generated technical note for release evidence.
- Adoption guide for external users.
- Versioned release notes.

## Next

- Add a multi-hop contradiction track.
- Add model-explanation scoring fields.
- Add more non-contradiction distractor controls.
- Add optional JSON Schema validation in CI when a schema validator dependency
  is available.
- Add third-party report submissions and review evidence.
- Draft an external announcement package around the release notes and generated
  technical note.

## Later

- Hidden/private evaluation split.
- Multilingual contradiction tracks.
- Long-context document contradiction track.
- Reliability diagrams and richer calibration review.
- Human review workflow for disputed cases.
- Archived suite snapshots.
