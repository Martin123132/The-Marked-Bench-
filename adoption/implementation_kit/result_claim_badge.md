# Marked Bench Result Claim Snippet

```markdown
[Marked Bench: SCORE on SUITE_ID vSUITE_VERSION](RESULT_CLAIM_URL)

This result is pinned to suite hash `SUITE_HASH` and release `RELEASE_ID`.
It is a public benchmark result, not a safety certification. Full evidence:
PUBLICATION_PACKET_URL
```

Replace the placeholders from `result_claim.json`:

- `SCORE`: `overall_score`
- `SUITE_ID`: `suite_id`
- `SUITE_VERSION`: `suite_version`
- `SUITE_HASH`: `suite_hash`
- `RELEASE_ID`: `release_id`
- `RESULT_CLAIM_URL`: public URL for `result_claim.json`
- `PUBLICATION_PACKET_URL`: public URL for `publication_packet.json`
